## Приоритет создания

### Критически важные (игра не работает без них):
1. Элементы Match-3 (fire, heal, sword, shield)
2. Портреты героев
3. Базовые враги (хотя бы 3-4)

### Важные (улучшают UX):
1. Иконки статус-эффектов
2. UI элементы (кнопки, панели)
3. Фоны

### Опциональные (можно добавить позже):
1. Эффекты частиц
2. Анимации персонажей
3. Все варианты снаряжения

## Технические требования

- **Формат**: PNG с прозрачностью (альфа-канал)
- **Разрешение**: Указано для каждого типа
- **Стиль**: Пиксель-арт или 2D рисованный (единый стиль для всей игры)
- **Цветовая палитра**: Тёмная фантазийная тематика
- **Оптимизация**: Сжатие без потери качества

## Временные заглушки

В данный момент игра использует цветные квадраты как заглушки:
- Огонь: красный квадрат
- Исцеление: зелёный квадрат
- Меч: оранжевый квадрат
- Щит: синий квадрат

Эти заглушки генерируются автоматически через `TextureGenerator.cs`.
