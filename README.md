# ⚔️ AlJourney

![Godot Engine](https://img.shields.io/badge/GODOT-4.x-478CBF?style=for-the-badge&logo=godotengine&logoColor=white)
![C#](https://img.shields.io/badge/C%23-239120?style=for-the-badge&logo=c-sharp&logoColor=white)

**AlJourney** — это уникальный гибрид головоломки в жанре **Match-3** и классической **ролевой игры (RPG)**. Игрок берет под управление сразу двух героев (Воина и Мага) и сражается с волнами противников, собирая комбинации элементов на игровом поле.

---

## 🎮 Геймплей

* **Боевая Match-3 система:** Собирайте мечи для нанесения физического урона, ману для заклинаний и зелья для лечения. Комбо-каскады увеличивают множитель урона!
* **Двойные Герои (Dual Hero):** Каждое действие на поле влияет на активного героя. Распределяйте ресурсы грамотно, чтобы выжить.
* **Глубокая RPG-составляющая:**
  * Более 14 видов уникальной экипировки.
  * Пассивные и активные способности для каждого класса.
  * Прогрессия сложности по мере прохождения волн.
* **Data-Driven архитектура:** Вся игра построена на строгом разделении данных и логики, что делает её невероятно легковесной и расширяемой.

---

## 🛠 Технологии и Архитектура

Проект написан на **C#** для движка **Godot 4**. 

Ключевые особенности кодовой базы:
* **Абсолютная SOLID-ориентированность**: Ключевые системы (Менеджеры) общаются друг с другом через строго заданные интерфейсы (например, `IGameStateManager`, `IInventoryManager`).
* **Асинхронность**: Боевая система полностью переведена на `async/await` с использованием `Task` и `ToSignal`, избавляя код от блокирующих таймеров и состояния гонки.
* **Отсутствие аллокаций в цикле (Zero-Allocation)**: Алгоритмы `Match3` поля (генерация, поиск совпадений) оптимизированы для сборщика мусора.
* **Документированность**: Абсолютно каждый публичный метод, класс и свойство имеют подробную XML-документацию (на русском языке).

*Подробную проектную документацию можно найти в папке `Docs/`.*

## 🚀 Запуск проекта

1. Установите [Godot 4.x .NET (C#) версию](https://godotengine.org/download).
2. Склонируйте или скачайте этот репозиторий.
3. Откройте проект (`project.godot`) в Godot Engine.
4. Нажмите кнопку **Build (Сборка)** в правом верхнем углу, чтобы скомпилировать C# скрипты.
5. Запустите игру кнопкой **Play** (или `F5`).

## 📂 Структура проекта

```text
AlJourney/
├── Docs/             # Проектная документация (Architecture, API, GameDesign)
├── Scenes/           # .tscn сцены Godot (Battle, MainMenu, UI)
├── Scripts/          # C# исходный код
│   ├── Battle/       # Боевая логика и фазы
│   ├── Characters/   # Классы героев и врагов
│   ├── Core/         # Базовые константы и перечисления
│   ├── Data/         # Базы данных (EquipmentDatabase, AbilityDatabase)
│   ├── Interfaces/   # Абстракции для менеджеров
│   ├── Managers/     # Синглтон-системы (GameState, Inventory, Loot)
│   ├── Match3/       # Движок головоломки
│   └── UI/           # Скрипты пользовательского интерфейса
└── Resources/        # Спрайты, шрифты, аудио
```
